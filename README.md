# kmt-parser

Парсер оптового каталога [kmt5.com.ua](https://kmt5.com.ua/) (KMT, Одесса) →
самообновляемый XML-фид с оптовыми ценами, точными остатками и характеристиками.

**Фид:** `https://<user>.github.io/kmt-parser/feed.xml`

## Что в фиде

| Тег | Значение |
|---|---|
| `<price>` | РРЦ, грн |
| `<vendorprice>` | «Ваша цена» (опт), грн |
| `<vendorpricedoll>` | «Ваша цена» (опт), $ |
| `<rrcdoll>` | РРЦ, $ |
| `<quantity_in_stock>` | точный остаток (сайт отдаёт его в листинге); фолбэк — оценка по метке |
| `<vendorCode>` | Ц-код («Код товара», общий у цветовых вариантов) |
| `<code>` | числовой «Код» |
| `<param>` | характеристики карточки + ступенчатые опт-цены («Опт від N шт») и Drop |
| offer id | id из публичного фида поставщика (`ts…`), фолбэк `ts`+цифры Ц-кода |

## Как работает

1. `crawl_listings.py` — обход корневых категорий (обнаруживаются динамически
   из меню, limit=100, пагинация) → `listings.json`: цена $, остаток, метка,
   ступенчатые опт-цены. Дедуп по product_id (~7 500 товаров). Каждый прогон.
2. `scrape_product.py` — карточки товара → `catalog.json` (кеш, коммитится):
   РРЦ, Drop/Опт, характеристики, фото 1000×1000, описание, хлебные крошки.
   Обычный прогон — только новые SKU; `REFRESH=1` — все (ночью).
3. `probe_qty.py` — **больше не нужен.** До редизайна 23.09.2026 сайт числа не
   показывал и остаток приходилось мерить корзиной; теперь он есть прямо в
   листинге (`data-max`, сверено с корзиной — совпадает). Скрипт оставлен как
   запасной, по умолчанию выключен (`STEP_QTY=0`).
4. `build_feed.py` — сборка `docs/feed.xml` (YML) для GitHub Pages.

Оркестратор `run.py`: шаги `STEP_LISTINGS` / `STEP_CARDS` / `STEP_QTY` (деф 0) /
`STEP_FEED` (env, 1/0).

## Расписание (GitHub Actions)

- `update.yml` — 3×/день (03:00, 09:00, 15:00 UTC). Ночной прогон (до 06:00)
  дополнительно пере-скрейпит карточки — РРЦ и характеристики есть только там,
  в листинге их больше нет; дневные обновляют цены и остатки.
- `refresh.yml` — вс 01:00 UTC, полный пере-скрейп карточек (фото/характеристики).

## Доступ

Логин обязателен (без него цены скрыты): секреты Actions `KMT_EMAIL`,
`KMT_PASSWORD`; локально — файл `.env` (в git не попадает).

## Локальный запуск

```bash
pip install -r requirements.txt
python run.py                       # листинги + новые карточки + фид
REFRESH=1 python run.py             # + пере-скрейп всех карточек (свежая РРЦ)
```

## Цены

Сайт показывает цены только в долларах, гривну считаем сами по курсу из шапки
(`meta.json`, обновляется каждым прогоном). «Ваша цена» — персональная оптовая;
`ladder` — ступенчатые скидки за объём (от 5/7/10 шт), они же в `<param>`.

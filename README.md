# kmt-parser

Парсер оптового каталога [kmt5.com.ua](https://kmt5.com.ua/) (KMT, Одесса) →
самообновляемый XML-фид с оптовыми ценами, точными остатками и характеристиками.

**Фид:** `https://<user>.github.io/kmt-parser/feed.xml`

## Что в фиде

| Тег | Значение |
|---|---|
| `<price>` | РРЦ, грн |
| `<vendorprice>` | «Ваша цена» (опт), грн |
| `<vendorpricedoll>` | «Ваша цена» (опт), $ |
| `<rrcdoll>` | РРЦ, $ |
| `<quantity_in_stock>` | точный остаток (замер через корзину); если замера нет — оценка по метке: много=100, в наличии=10, мало=3 |
| `<vendorCode>` | Ц-код («Код товара», общий у цветовых вариантов) |
| `<code>` | числовой «Код» |
| `<param>` | все характеристики карточки |
| offer id | product_id сайта (уникален для каждого варианта) |

## Как работает

1. `crawl_listings.py` — обход 14 корневых категорий (limit=100, пагинация) →
   `listings.json`: цены $, грн, РРЦ, метка наличия. Дедуп по product_id
   (~9 200 товаров). Быстро, каждый прогон.
2. `scrape_product.py` — карточки товара → `catalog.json` (кеш, коммитится):
   характеристики, фото 1000×1000, описание, хлебные крошки, числовой код.
   Обычный прогон — только новые SKU; `REFRESH=1` — все (еженедельно).
3. `probe_qty.py` — точный остаток: сайт числа не показывает, но корзина
   обрезает заказ до фактического остатка (add 9999 → `in_cart`). → `qty.json`.
   ⚠️ Полностью очищает корзину аккаунта до и после — не запускать во время
   набора реального заказа. ~30 мин на весь каталог.
4. `build_feed.py` — сборка `docs/feed.xml` (YML) для GitHub Pages.

Оркестратор `run.py`: шаги `STEP_LISTINGS` / `STEP_CARDS` / `STEP_QTY` (деф 0) /
`STEP_FEED` (env, 1/0).

## Расписание (GitHub Actions)

- `update.yml` — 3×/день (03:00, 09:00, 15:00 UTC). Ночной прогон (до 06:00)
  дополнительно замеряет точные остатки; дневные обновляют цены/метки.
- `refresh.yml` — вс 01:00 UTC, полный пере-скрейп карточек (фото/характеристики).

## Доступ

Логин обязателен (без него цены скрыты): секреты Actions `KMT_EMAIL`,
`KMT_PASSWORD`; локально — файл `.env` (в git не попадает).

## Локальный запуск

```bash
pip install -r requirements.txt
python run.py                       # листинги + новые карточки + фид
STEP_QTY=1 python run.py            # + точные остатки
REFRESH=1 python scrape_product.py  # пере-скрейпить все карточки
```
